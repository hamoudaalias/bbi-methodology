## Rule 7 — Every gate must define the verdict for each failure direction

> A spec that only describes "success" and "no difference" leaves a gray
> zone when the effect goes the wrong way consistently.

**Generating fact** ([[Report Ablation C3]] addendum) : the Sprint B script
printed "NOT CONCLUSIVE" while the mechanistic reversal was frank (2/2
families) — verdict revised to "NEGATIVE DIRECTIONAL" by the CP.

**Application** : every pre-registered gate must specify PASSED / NEGATIVE
DIRECTIONAL / NOT CONCLUSIVE — with the criteria of each — before the run.

## Lesson 31 — The task portal authorizes, but the prediction symmetry is DETECTED on the target — that is where the measurable ×5 was found

(Phase 12 — TASK abstraction, post-closure, 2026-09-08, VERDICT VALIDATED, 325 PASS / 0 FAIL)

**Lesson :** *one more abstraction level — the TASK (abstract objective + action
types {maintain, redirect, amplify} + symmetry) — transforms a structural
transfer "≤ ×4" into a measurable ×6.4 gain, provided one applies the Lesson 29
principle to the end : the task portal (objective, action, A's re-verified
principles) AUTHORIZES the transfer, but the exploited prediction structure — the
anti-phase or cyclic symmetry — must be DETECTED ON THE TARGET, never rebuilt
from the source's principles. Rebuilding the symmetry from what A verifies
flattens it (×1.0 gain, C), detecting it on B makes it useful (×6.4 gain, C).*

Three measured facts underpinning the lesson :

1. **The bug that demonstrates it** : the N2 mirror (verify → `tb.symetrie`
   rebuilt from A's principles) reduced C to "none" (A only has
   cycle_service, C is anti-phase) → "cold" class → ×1.0 gain. The decision to
   transfer the HYPOTHESIS CLASS — not the symmetry — and to detect B's native
   symmetry (voted over 3 seeds) restores the anti-phase (E·s(g)) on C and the
   cyclic rotation (E_base + shift by blocks) on D.

2. **The gain comes from the class, not the numbers** : on C, K_warm goes from
   10.75 (cold) to 2.5 (N3 anti-phase head) → ×6.4 gain (the Chef's ×5 criterion,
   unreachable in Phase 11, becomes measurable at Level 3). The N3 head carries
   NO numerical value from the domain — the magnitude vectors are learned on the
   target, only the class is transferred.

3. **Honest refusal does not change behavior at Level 3** : B (0.00, energy
   objective) and RAD-C (0.65, amplifier action portal ≠ redirect) are refused
   exactly as at Level 2 — the portal is hard, there is no N3 head, cold start.

**Warning signal :** a transfer pipeline that reports the head's symmetry by
copying the one presented by the SOURCE (even re-verified) systematically
underestimates the gain — and a verdict "< ×4 everywhere → project closed" can
be an artefact of this reporting, not a physical limit.

**Application :** task portal (objective, action, physically re-verified
principles) for the verdict ; native symmetry of the target voted for the
hypothesis class ; magnitude learned on the target. **Corpus brought to 31
lessons.**

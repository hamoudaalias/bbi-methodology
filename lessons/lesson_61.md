# Lesson 61 — The learning gain IS the identification

**When :** Causal RL J1-J4-P10, 2026-09-17/18 (E-W-C-P-L-A-T-I-K·A²·P_seq, Phase 10 AGI), sealed spec `9551194a…` (Option A re-sealed observation = roles-only projection). J4-P10 on the holdout **91700-91799** : CE1 20/20 (`7908b26c…`), **CE2-P10 = 1.000** (fixed 0.330 / greedy 0.000), discriminant class n = 34 : P_learn **34/34** vs fixed **0/34**, no-probe ablation **0/34** ; **G_learn = 1.000** (CI 1.000-1.000), G(0) = 0.000 (baseline ≡ fixed by exact plan identity), G(1) = 1.000 (CI LB 1.000), G(1)−G(0) = 1.000 (CI LB 1.000) ; CE3 33 probes / **0 forcing** ; CE5 max 2 510 nodes, probe histogram {0: 43, 1: 57} ; CE4 secondary pre-mapped (identification rate 1.00) → **verdict POSITIF** — the **first POSITIVE verdict of the AGI trajectory** (10th property : policy refinement by deterministic causal exploration).

**Context / tension :** three instrument-level tensions, all caught by the protocol's own assertions. (1) **A measurement bug found by the causal gate itself** : the first J3-T3 run counted "solved" in the *learner's model* instead of rolling the plan out in the **true dynamics** — the assertion "no-probe must fail on mode B" is what exposed it ; the fix (true-dynamics roll-out for T3 and T4) was made before reporting, not after a favourable number. (2) **A half-open range off-by-one against the sealed text** : the spec says "91600-91699 (100 tasks) ; 91700-91799 (100 tasks)" but the code had half-open bounds `(91600, 91699)` / `(91700, 91799)` = **99/99** — seed 91699 (devel) and seed **91799 (holdout)** were silently outside the family. Detected at J4 by comparing the pool size against the sealed count, **repaired before committing any J4 artifact** (bounds → `(91600, 91700)` / `(91700, 91800)`), and **every affected step re-measured** : J1 8/8 PASS with unchanged counts (A-2 38/66, A-3 28), J3 byte-identical result JSON (`4f8e5e8b…`), J4 re-run on the true 100/100. (3) **G(0) literal "CI LB > 0" in the sealed §5 cannot hold** : the k = 0 ablation ≡ the fixed policy *by exact plan identity*, so G(0) ≡ 0 with zero variance — a degenerate CI is a property of the definition, not of the mechanism ; the CP-order J4 reading (G(0) as the baseline) is operative and the degeneracy is published.

**Lesson :** 1) **the learning gain is the identification itself** — when a sealed 1-bit probe separates the hypothesis class, the entire 0.000 → 1.000 gain is carried by probe + exact elimination (no-probe ≡ fixed policy exactly, purge ≡ fixed policy exactly) ; a probe-less learner *is* the fixed policy, not a weaker version of it ; 2) **G(0) is an identity, not a measurement** — publish it as ≡ 0 with its degenerate CI instead of dressing it as a small positive number ; 3) **write gates that can falsify the instrument** — the "no-probe must fail" assertion is precisely what forced the honest roll-out semantics ; an ablation used as a gate must always be evaluated in the **true dynamics**, never in the model's own semantics ; 4) **sealed arithmetic must be transcribed as executable boundaries** — a family window ("100 tasks") belongs in code as an exact count with an assertion, because half-open ranges silently shrink families by one, and a missing holdout seed is an integrity bug even when every metric looks green ; 5) **repair-before-commit is not a threshold move** — re-running every affected artifact before the first commit of the step keeps the claim testable and honest (the correction is published, not hidden) ; the same repair after a commit would be a protocol violation.

**Application :** 1) at J0 transcription, encode each sealed family window with `assert len == <sealed count>` ; 2) any "must fail" gate (ablation, purge, baseline) is measured by true-dynamics roll-out ; 3) publish degenerate (zero-variance) CIs with the reason ; 4) when an instrument is corrected pre-commit, re-run every affected step and report the deltas (here : none semantically, byte-identical J3) ; 5) a 1-bit intervention suffices when the probe separates the class — the claim is about identification, never about probe volume.

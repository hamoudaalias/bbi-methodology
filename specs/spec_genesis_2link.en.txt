1. SCIENTIFIC QUESTION
Does BBI preserve H0 bit-identical, Causal Touching, and the
E-W-C-P-L loop when the body goes from 1 degree of freedom (pendulum Alpha) to
2 degrees of freedom (2-segment planar arm, hidden terminal mass)?

2. PHYSICAL MODEL (2-segment planar arm, pure NumPy, float64)
EQUATION OF MOTION (standard form):
    M(q)·q̈ + C(q,q̇)·q̇ + G(q) + B·q̇ = τ
    q = [q1, q2] (rad), q̇ = [ω1, ω2] (rad/s)

CONVENTIONS (FROZEN):
- Vertical plane (gravity pointing downward).
- q1 measured from the DOWNWARD vertical (hanging = 0 = stable equilibrium).
- q2 RELATIVE; direction of segment 2 = q1+q2. q2 = 0 = segments aligned.
- Trigonometric positive direction; τ_i > 0 = q_i increasing.

PHYSICAL CONSTANTS (FROZEN):
    g  = 9.81 m/s²
    l1 = 0.400 m   (segment 1)
    l2 = 0.400 m   (segment 2)
    m1 = 1.00 kg   (segment 1 KNOWN, uniform rod)
    m2 = unknown, HIDDEN VARIABLE ∈ [0.5, 5.0] kg (uniform rod,
         terminal mass / payload)
    b1 = 0.80 N·m·s (KNOWN viscous friction, fixed)
    b2 = 0.80 N·m·s (idem)
    dt = 0.02 s (50 Hz) — justified: continuity with Alpha; inertias
         scaled (l=0.40, m1=1.0) so a_max·dt ≃ 0.2 rad/s
         (RK4 stable, 5000 steps verified), probe response ~0.2–0.31
         rad/s measurable in float64.
Uniform rods: a_i = l_i/2, I_i = m_i·l_i²/12.

M(q) (c2 = cos(q2)):
    M11 = m1·l1²/3 + m2·(l1² + l2²/3 + l1·l2·c2)
    M12 = m2·(l2²/3 + (l1·l2/2)·c2)
    M22 = m2·l2²/3

C(q,q̇) (h = −m2·l1·(l2/2)·sin(q2)):
    C11 = h·q̇2 ;  C12 = h·(q̇1 + q̇2) ;  C21 = −h·q̇1 ;  C22 = 0

G(q):
    G1 = −(m1·a1 + m2·l1)·g·sin(q1) − m2·a2·g·sin(q1+q2)
    G2 = −m2·a2·g·sin(q1+q2)

B : diag(b1, b2) = diag(0.8, 0.8)

INTEGRATOR: homemade RK4, float64, step dt, q wrapped on [−π, π].
q̈ = M(q)^{−1}·(τ − C·q̇ − G − B·q̇).

ENERGY (deposited RAW in the world, as in Alpha):
    cum_energy += (τ1² + τ2²) at each step (N²·m²·dt).
    Never projected; the audit recomposes it exactly.

5. CAUSAL TOUCHING BETA (FROZEN) — 1 pair H0 = probe + null, W inversion
PROTOCOL (1 pair suffices, ANALYSIS below):
    rest → snapshot → probe (τ=(+2.5, 0) N·m, 1 step) → Δz_world

ALGEBRAIC ANALYSIS (continuous, dt→0) — at rest q=[0,0], q̇=[0,0]:
    A = m1·l1²/3 ;  B = l1² + l2²/3 + l1·l2 ;  C = l2²/3 + (l1·l2)/2 ;
    D = l2²/3.
    Δω1 = p·D·dt / (A·D + m2·(B·D − C²))
    Δω2 = −p·C·dt / (A·D + m2·(B·D − C²))
    KINEMATIC INVARIANT: Δω2/Δω1 = −C/D = −2.5 (independent of m2).
    CLOSED FORM: m2 = (p·D·dt/Δω1 − A·D)/(B·D − C²).
    DEGREES OF FREEDOM: 1 unknown, 4-vector response (q1,q2,ω1,ω2) →
    overdetermined → 1 pair suffices.

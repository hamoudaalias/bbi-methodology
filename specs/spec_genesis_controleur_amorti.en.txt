# Design Doc Damped Stabilizing Controller J0 — Explicit damping in Layer P

**BBI programme — Damped Stabilizing Controller (Lesson 49).** Workstream
opened by porteur decision (GO 2026-09-14). The **Perceptive Encoder v2**
extension is **closed on PARTIAL** (CE4 PASS 3/3 saturated · CE5 PARTIAL 9/30 —
Lesson 49, `Perceptive Encoder v2 J4 Report…`). Lesson 49 documents the exit
door: *"any exit path after a rich channel passes through the controller:
explicit damping, systematic ω̂_LONG, maintain-vs-approach planning — with a
new J0 and a D1-D5 diligence, never a post-measure threshold adjustment"*
(`BBI Methodological Lessons.md:1643`, `Journal d'Audit.md:4371`).

> ⚠️ **This programme is NEITHER a relaunch of the Perceptive Encoder v2 NOR a
> threshold adjustment.** The perceptive programme stays **closed on PARTIAL**
> (Lesson 41 per programme). The v2 specs (`52ec1014…`), seeds (92_000-92_119)
> and criteria **do not move**. This J0 is a **new programme** targeting
> **only layer P** of the physical E-W-C-P-L chain (`python/genesis/`).

**Falsifiable scientific question:**

> *Can BBI **STABILIZE** (CE5) a dynamic target — not merely approach it — if
> layer P of the v2 loop replaces the instantaneous ω̂ of its sliding
> prediction with a **systematic long-window estimate** ω̂_LONG (sliding
> average over the ω̃ window, K = W_CAP = 32) and adopts a **two-phase
> MAINTAIN-vs-APPROACH policy** (phase threshold γ = 0.10 rad)? The bottleneck
> has been localized to the controller (Lesson 49: CE4 saturates at 1.0 while
> CE5 stays PARTIAL, with P the only unchanged stage during v1→v2). The damping
> controller must raise stabilization from **9/30 to ≥ 25/30 virgin eval seeds
> (93xxx)**, with E, channel, W, C, testbed and dynamics **frozen**.*

**Discipline:** no threshold tuning, no parameter added post-measurement, no
seed chosen after the fact. Every parameter fixed below is sealed in the J0
before any experimentation.

## 5. ω̂_LONG specification (diligence D2 — design, frozen)

**Chosen estimator: family B' — arithmetic sliding average over ω̃.**

```
ω̂_LONG[t] = (1 / W_CAP) · Σ_{i=0}^{W_CAP−1} ω̃[t−i],   W_CAP = 32
```

- **Input:** the v2 loop's sliding buffer `_buf_omega` (last 32 sensed ω̃
  values, float64, window = W_CAP = 0.64 s, aligned with H0 v2). **No** hidden
  state reads; **no** finite-difference operator on θ̃ (noise ε ≤ 0.02 would be
  amplified) — we average already-sensed ω̃.
- **Determinism:** float64 sum/division over a buffer of deterministic captures
  (bits fixed by the channel+seed chain) → bit-identical; summation order fixed
  (explicit indexed sequential summation, not an unspecified reducer).
- **Initialization:** until the buffer holds W_CAP readings (v2 warmup), ω̂_LONG
  is **unavailable** → `omega_long = None` → strict fallback to baseline
  (`om_init = w_base`, exactly as today).
- **Missing values:** any window entry flagged `missing[]` (failed re-capture,
  NaN forbidden) ⇒ **never imputed**: the window is declared unavailable →
  `None` → fallback. Honest per-cycle `missing[]` accounting (v2 N4 pattern,
  never patched).
- **Signature:** `omega_long_wcap(omega_buffer) -> float | None` (module
  `controller_amorti.py`, pure function, isolable test).
- **Contract:** finite and `|ω̂_LONG| > 1e-9` to enter the existing
  `_P(..., omega_long)` slot (`:220-224`) — no other use.

## 6. Two-phase MAINTAIN-vs-APPROACH policy (diligence D2, frozen)

**Single sealed phase threshold:** `γ = 0.10 rad` (aligned with the success
band SEUIL_C5 = 0.1). One value, **no sweep**.

**Phase rule (exact condition, evaluated each cycle before action choice):**

```
σ   = (θ − θ_cible) + LAM_SLIDE · ω̂_LONG        # ω̂_LONG if available, else buffer ω̃
APPROACH  if  |σ| > γ
MAINTAIN  if  |σ| ≤ γ
```

- **APPROACH** (outside the band): argmin over `CAND` of `|σ′_a|` predicted by
  W (RK4, `om_init = ω̂_LONG` if reliable) — **identical to baseline** (same
  sliding surface, same tie-break `(|τ|, a)`).
- **MAINTAIN** (inside the band, the currently-failing case — transient
  stabilization 1..18 cycles): W predicts `(θ′_a, ω′_a)` over 2 RK4 steps for
  the 5 torques; choose `a*` minimizing, in order:
  1. `|ω′_a|` (damp — first priority in the band),
  2. drift sign toward θ_cible consistent with `σ` (do not overshoot),
  3. `|τ_a|` then index (energy, Principle 4).

**Falsifiable rationale:** the CE5 failure is the non-lock
(`|θ(50)−θ_cible| ≤ 0.1` not held, oscillation around the target). Trapping ω
inside the band through explicit damping must remove target crossing. If ω̂_LONG
or the MAINTAIN rule change nothing (≤ 9/30) → NEGATIVE published.

**Hardening:** γ is **not** a verdict threshold — it is a *policy* parameter
sealed once. Its value 0.10 ≤ SEUIL_C5 guarantees that entering MAINTAIN never
equals success before the final read.

## 0. Starting situation — why a new programme, and not a relaunch

Two extensions built the "E encodes an observation" framework: the continuous
physics observes the **continuous state** (θ, ω) directly; Visual Perception
observes **pixels** (2D uint8 64×64 render) and produced two consecutive
failures. Carved lessons :

- **Lesson 40** — in perception, the **perceptive information loss** (pixel
  channel) is structural: a threshold calibrated on a diligence allocation
  does not hold on the evaluation allocation. The loss must be **provisioned
  into the threshold**, not discovered at J3. Measured: sealed ref 0.8702,
  v2 provisioned 0.88, obtained 0.8637.
- **Lesson 41** — **two consecutive failures on the same extension, with the
  same cause, = definitive closure by default.** Visual Perception is closed,
  not relaunched.
- **Lesson 42** — a decision function that depends on a single variable
  available at the first horizon makes horizons indistinguishable; the test
  measures the chain construction, not anticipation.

Methodological reading: the **pixel** channel was the wrong abstraction of the
loss — not perception in general. The perceptive counterpart that reproduces
neither the pixel loss (Lesson 40) nor a single cause unfalsified by path
(Lesson 41) is a **1D sensor channel**: quantised read of sin θ, bounded
noise. The CP arbitration slices **Chantier A — Perceptive Encoder**, defined
as: **one scientific question, three independent encoding paths** — each with
its own operational definition, its oracle ceiling (R2) measured in diligence,
its criteria and its cut-off. A failing path is **NEGATIVE published** and
**does not drag the others down** (Lesson 41 applied **per path**, not per
programme).

## 1. Objective

Extend the **E (Encoder) layer** to **raw sensor perception** on the sealed
physical testbed: BBI reads a **quantised and noisy 1D stream** of the
pendulum's projected position, must extract a **causal latent representation**
(angle, velocity, visible dissipation), and **reason causally** on top of it —
infer the hidden mass by **intervention** (perceptive Causal Touch), predict
the perceptive effects of actions (W), measure causal attribution by stream
difference (C), choose (P) and trace (L) — **as before**, on this latent.

Three deterministic encoding strategies are pre-registered and evaluated
**independently**:

| Path | Central idea | Identified risk (documented) |
|---|---|---|
| **A — Modal** (Fourier / wavelets) | sliding spectral representation of the stream (STFT + numpy Haar DWT) | non-periodic dynamics (strong friction, transients) → blurred dominant frequency |
| **B — Geometric** (line / circle / contour primitives) | primitives of the reconstructed phase plane (segments, arcs, circles, envelope) | fragile primitive detection under quantisation/noise → tolerant global fit required |
| **C — Adaptive sampling** (relevant regions) | the encoder reads only an adaptive subset of informative points (extrema, derivative zero crossings) | failing selection regulation → context loss (declared `missing[]`, never filled) |

**Non-objectives:** no camera nor pixels (Perception closure, Lesson 41), no
deep learning (forbidden §10.1), no infinite continuous variables, no closed
form of the world equations, no decision on a real sensor.

## 2. Specification (SEALABLE — contained in this document, SHA imprint §9)

### 2.1 Domain — 1D perceptive channel (sensor stream of the sealed pendulum)

**Physical testbed:** Alpha's damped pendulum (**`GenesisArmEnv`**, SEALED
Alpha — same dynamics, hidden mass m∈[0.5,5.0] kg, sealed friction b∈[0.1,2.0],
quantised torques, dt=0.02 s, initial rest observation). Reused as-is,
**never modified** (CP decision: correction/extraction agent-side).

**Perceptive channel (the only input of E):** pure function `capture(state) →
u ∈ ℤ_{0..255}^W` :

- at each sensor step `t_k`, **1D** read of the projection: `s_k = sin(θ(t_k))`
  (non-linear projection, like the 2D camera, but **without spatial render**) ;
- **quantisation**: `q_k = round(127.5·(1 + s_k))` → scale 0..255 (uint8) —
  the pendulum is seen by a discretised sensor ;
- **bounded sensor noise**: `u_k = clip(q_k + n_k, 0, 255)`, `n_k = U(−ε, +ε)`
  rounded to integer, ε fixed **per seed** (ε ∈ {0, 1, 2} quantum levels —
  quantisation variants, mirror of the discovered testbed noise matrix, pure
  function of the seed) ;
- the observed window `W_cap` = 32 sensor steps (0.64 s), sliding.

Justification: (a) it is the **minimal generalisation** of the state channel:
the 1D quantised sensor keeps the causality of the sealed POSITIVE physical
testbed while introducing a **bounded and adjustable perceptive information
loss** (ε) — Lesson 40 is handled by **measured provisioning**, not by a pixel
channel; (b) **H0-compatible**: `capture` is pure and deterministic (seeded
for n_k) → bit-identical snapshot/restore enforceable; (c) **0 exotic asset** —
pure NumPy; (d) the sinusoidal projection is NOT directly the angle → the
encoder must **de-project** (visual-chamber mirror, without the pixel
collaterality).

The **real physical sensor** (noise, non-replayable calibration) is explicitly
**out of J0-J4 scope** (bit-identical H0 requires a replayable world) — future
extension documented, never weakened.

### 2.2 Input of E and latent representation (3 paths, 0 deep learning)

**Common input:** stream `u = (u_1..u_Wcap)` (uint8) + **previous** stream `u′`
(1-step memory for temporal derivatives). **Output:** `z_v = E_V(u, u′) ∈ ℝ⁸`,
path V ∈ {A, B, C}.

**Path A — Modal (spec `perc_encoder_modal.py`)**

1. **STFT** numpy (hann window 16, hop 8) on the stream → spectrum matrix
   `S[t,f]`;
2. **pure numpy Haar DWT** (level 3, filters [1,1]/[1,−1]/√2) → approximation/
   detail bands;
3. **ω̂ modal** = instantaneous phase derivative of the fundamental component
   (dominant frequency by weighted argmax over 3 bands [0.1, 0.5, 1.0]·f_nyq);
4. **θ̂ modal** = unwrapped phase of the fundamental component (arcsin
   association of the projection — de-projection);
5. z_A = `[cosθ̂, sinθ̂, ω̂, E_total, E_band1..3, spectral_coherence]`;
6. if no stable dominant component (diffuse energy, saturated stream) →
   **`missing[]` declared** (never filled).

Assumed and documented risk: strong friction ⇒ fast damping ⇒ widened spectrum
(non-stationary transient) — handled by **measured non-stationarity** and
honest refusal, never by force.

**Path B — Geometric (spec `perc_encoder_geom.py`)**

1. **Reconstructed phase plane** `(u, Δu)` (u̇ ≈ robust finite difference on
   the uint8 stream);
2. **Primitives** extracted — pure NumPy:
   - line segments (recursive Ramer-Douglas-Peucker approximation, tol 5);
   - **arcs / circles** (least-squares circle fit on sliding triplets,
     radius ≥ 2 px, sealed internal tolerance);
   - **envelope** (convex hull / extrema of the phase cloud);
3. **z_B** = `[dominant_circle_radius, centre_x/y, dominant_segment_slope,
   ω̂_geom (circle-angle derivative), radius_min/max, envelope_compactness,
   energy]`;
4. if no stable primitive (formless cloud) → **`missing[]`** declared.

Assumed risk: quantisation+noise deform the primitives → a tolerant, coherent
global fit (no learned parameter), verified by the non-causal invariance
(§8 T_perc_7).

**Path C — Adaptive sampling (spec `perc_encoder_sample.py`)**

1. **Adaptive selection** of the stream's relevant regions: local extrema
   (|Δu| ≥ adaptive per-window threshold), derivative zero crossings,
   maximum-derivative points (top-k) — treats ~20 % of the points;
2. **Reconstruction**: causal interpolation (numpy cubic spline between
   retained points) / damped kernel (sealed internal sigma) → dense
   reconstructed signal;
3. **z_C** = number/positions of the extrema, amplitudes, zero-crossing
   instants (→ period → ω̂), inter-extrema slopes (→ dissipation), per-point
   confidence (`missing[]` if < 3 reliable extrema on the window);
4. systematic honest refusal if the selection regulation fails.

Assumed risk: context loss → declared `missing[]`, measured by perceptive
scarcity (§8), never invented.

**Common properties (sealed):** zero width of the free parameters ⇒ 0 deep
learning, bit-identical replay (T_perc_1). z_v is **quasi-state**: W predicts
the next z_v from (z_v, action) without reading the exact state. **The mass m
stays hidden**: no feature of a stream contains it — it is inferable only by
**intervention** (Touch §2.5), tested on the perceptive differential.

### 2.3 Model W — PERCEPTIVE effects of actions (deterministic, pure NumPy)

The "world": Alpha's sealed dynamics (Lagrange, RK4, quantised torques,
m ∈ [0.5,5.0], b ∈ [0.1,2.0]) **serves as ORACLE** (truth — readable by C and
L only, §10.5). **W** is the same operator **conditioned on the perceptive
latent**: `W(z_v, a) → ẑ′_v` (prediction of the next z_v). Criterion CE4:
"C measures z_v_causal (do-vs-null stream difference), W predicts the same
quantity" — the fidelity is measured on the **perceptive causal differential**,
not on raw z (mirror Alpha C4 / Vision CV4). **W never touches the hidden
state**; it predicts ẑ′_v through a path image model (sinusoidal projection,
same RK4 stencil as the env, Eq. A5) then E_V(Î′) → ẑ′_v. No oracle call in
W (T_perc_5).

### 2.4 PERCEPTIVE H0 protocol — snapshot/restore of the OBSERVATIONS

The "observation" = the **raw stream** `u` (uint8) + derived features.

- **Snapshot**: `bytes(u)` = `u.tobytes()` + `hash(u)` + exact sensor state
  (repr, arr, noise seed ε).
- **Restore**: refeed/compute E → decorrelate → same `u` → E_V(u, u′)
  identical.
- **Bit-identical required**: `np.array_equal(u_restored, u_snapshot)`
  otherwise FAIL (T_perc_2).

The counterfactual operates on the **streams**: `do(var:=val)` re-captures the
stream with the variable replaced; `null` re-captures the nominal value. The
**stream difference** `Δu = u_do − u_null` is the **perceptive attribution** of
the pair (mirror H0 + Touch, but on the 1D stream).

### 2.5 PERCEPTIVE Causal Touch — inference by intervention, measurement on streams

Hidden mass impossible to read on a stream (§2.2) → **minimal intervention**:
a **K-step window (0.4 s) at constant τ** (1 step = detectable stream
variation, the 1D sensor is more sensitive than the sub-pixel), torque pair
`(a_probe=3, a_null=2)`, from rest. From the **PERCEPTIVE angles θ̂_e**
(successive, regardless of the path — de-projection of u by the path),
identification through the dynamics' **exact damped kernel** (same modality as
W — physics, not threshold fitting):

    θ̈ = A − (g/L)·θ − 2γ·θ̇   →   θ̂(A,t) = A·Ψ(t),
    Ψ(t) = [1 − e^{−γt}·(cos ωd t + (γ/ωd)·sin ωd t)]/ω0²,  ω0² = g/L,
    A = Σ θ̂_e(t)·Ψ(t) / Σ Ψ(t)²   →   m_est = τ/(A·L²).

The **latent damping rate γ̂** comes from a dedicated Friction probe (kick
then coast, logarithmic decrement of the perceptive extrema —
**m-independent**) → **3-pass latency** (`m̂₀` dry kernel → `γ̂` coast → refit
`m̂`, then `b̂ = 2γ̂m̂`). The null branch (τ=0) is subtracted (counterfactual).
**Error < 15 % required** (CE3 — mirror Alpha C3 / Vision CV3; Lesson 40
provision: the threshold is FROZEN at 15 %, the margin provided by the 1D
channel vs pixel is measured in diligence). **Perceptive counterfactual**:
`capture(θ̂, ω̂, m̂, a) vs capture(θ̂, ω̂, m̂, a_null)` → Δu attribution ≥
threshold ⇒ "perceptive link" (T_perc_4). Scope: inference of **mass &
friction**; C, E, R, L sole legitimate readers of the exact state (C/L: §10.5;
E/R: stream only).

### 2.6 PERCEPTIVE E-W-C-P-L loop

| Layer | Perceptive role |
|---|---|
| **E** | `z_v = E_V(u, u′)` (path V, §2.2) — 0 deep learning |
| **W** | `W(z_v, a) → ẑ′_v, ẑ′_v_null` (perceptive effects, never the hidden state) |
| **C** | measures the causal effect: `Δz_v = z_v_do − z_v_null` on **re-captured streams** (12-step/0.24 s measurement window, base velocity measured); attribution by `Δu`; emits the perceptive causal chain JSON |
| **P** | chooses `a ∈ {a_probe, a_null, ±5, ±2.5, 0}` by \|σ′\| predicted by W, **with horizon-dependent information** (Lesson 42: the long perceptive window provides spectral bands / primitives / extrema that do not exist at short horizon → progressive anticipation tested, not only chain construction) |
| **L** | JSONL journal: `flux_hash`, z_v, action, Δu_energy, Δz_v, m_est, verdicts per path |

### 2.7 Output L — Perceptive protocol fields (JSON)

`flux_hash`, `step`, `z_v[]`, `voie`, `action`, `z_pred`, `z_null_pred`,
`delta_flux_energy`, `chain[]` (perceptive links: `feature`, `Δu`,
`direction`, `accord`), `m_est`, `frottement_est`, `prediction`
(stabilised / oscillation / indeterminate), `missing[]` (features
non-informative at this step — never invented).

## 7. Cut-off (pre-registered — Chef decision §6.3#8)

**NEGATIVE VERDICT (per path)** if, on the path's sealed evaluation:
1. **CE1 (perceptive determinism) fails** — the bit-identical replay (stream +
   z_v) is the condition of any reproducible science;
2. **CE2 (perceptive H0) fails** — the bit-identical snapshot/restore of the
   perceptive observations is the foundation of the counterfactual;
3. **CE3 (perceptive Causal Touch) fails** — inference by intervention on a
   sensor stream is the heart of the question (§0);
4. **CE4 fails by crash / NaN / oracle leak** (unstable loop or E/W/P reading
   the exact state).

**CE5:** objective — if it fails alone, **PARTIAL** verdict for the path
(causal perception is proven; manipulation remains a limit — published, never
masked). **Programme closure**: 3 NEGATIVE paths (Lesson 41 applied by
programme beyond the per-path clause) — CP decision, published.
**No threshold/p fitting after measurement** (forbidden §10.7).

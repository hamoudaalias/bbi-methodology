1. SCIENTIFIC QUESTION
Can BBI reason causally on REAL-TIME FINANCIAL DATA
(historical volatility, macroeconomic indicators,
market sentiment), with the SAME primitives as on continuous
physics and symbolic EU261: H0 (snapshot/restore), Causal
Touch (measured counterfactual), Causal Module C, E-W-C-P-L
loop — an architecture that extends, not a collection of programs?

The observation is PARTIAL BY HORIZON: available information
grows from H-5 to H-0. Some variables remain UNOBSERVED at the
current horizon — they are DECLARED or the agent responds
"undetermined" (epistemic honesty), never fabricated.

2. DOMAIN — YAHOO FINANCE + FRED PROTOCOL (FINANCIAL MARKETS)
One CASE = one SPY trading day: a sequence of macroeconomic and
technical events, a target volatility regime, and the decision
horizon. The task, at EACH horizon, is to anticipate the day's
trading volatility regime and rule:
    high (volatility > threshold) / low / undetermined
    direction (up/down): bullish / bearish / undetermined

4 HORIZONS (increasing information, fixed set per horizon):
    H-5: previous week's macro data (CPI, PPI, PMI, rates)
    H-3: + technical data (RSI, MACD, Bollinger) + volume
    H-1: + intraday data (open, high, low, close, volume)
    H-0: + final state (close, full range) — complete case state
(variables not yet available at the horizon are DECLARED MISSING
— see §8 honesty).

4 LEVELS OF CAUSAL COMPLEXITY:
    N1  direct cause (1 link: e.g. high CPI → high volatility)
    N2  2-link chain (e.g. rates → volatility → direction)
    N3  chain + interactive causes (e.g. volume × Bollinger × macro)
    N4  chain + EXTREME circumstance + missing variable

VOLUMES: 128 main cases + 60 trap cases P1..P7 (pre-registered §8).

3. SYMBOLIC REPRESENTATION — CAUSAL VARIABLES
6 observable causal variables depending on horizon:
    macro_i   ∈ {normal, high, extreme}   inflation (CPI/PPI)
                                           associated EXTREME flag:
    ext_i     ∈ {no, yes}                 EXTREME circumstance
                                          (not observable at H-5)
    taux_i    ∈ {stable, increase, decrease}  policy rates (Fed)
    volume_i  ∈ {normal, high, very_high}    trading volume
    bollinger_i ∈ {inside, outside}          Bollinger relative position
    rsi_i     ∈ {normal, overbought, oversold}  RSI

ONE CAUSAL LINK = a non-nominal variable whose contribution
to volatility is significant (measured by the COUNTERFACTUAL §6).
Nominal values: macro=normal, taux=stable, volume=normal,
bollinger=inside, rsi=normal.

E ENCODING: z = one-hot/ordinal vector of the SET of all
variables observable at horizon h (missing ones are encoded by the
token MISSING — never replaced with a value).

4. W MODEL — VOLATILITY PROPAGATION (deterministic, NumPy)
This is the financial "world": the same deterministic function serves
as ORACLE (ground truth) and as base belief W (world model).

Realized historical volatility (5 days):
    σ_5d = sqrt(252) * std(daily_returns[-5:])

Realized historical volatility (20 days):
    σ_20d = sqrt(252) * std(daily_returns[-20:])

Volatility signal:
    σ_ratio = σ_5d / σ_20d
    regime  = high if σ_ratio > 1.5  (pre-registered threshold)
              low otherwise

Causal contribution (counterfactual delta):
    Δσ = |σ_ratio(w/intervention) - σ_ratio(w/without intervention)|

Contribution per variable:
    δ_macro    = contribution of the inflation regime
    δ_taux     = contribution of rate variation
    δ_volume   = contribution of abnormal volume
    δ_bollinger = contribution of band breakout
    δ_rsi      = contribution of extreme RSI
    δ_ext      = contribution of extreme circumstance

THE ORACLE (ground truth) IS THE W MODEL ITSELF (CP vigilance 3.2):
the same deterministic function §4 serves as oracle and as base
belief. The oracle is NOT a complete case state (unlike EU261) —
it is the target regime computed on FROZEN data §14. The W model
must be calibrated so that the oracle is NON-TRIVIAL but
ACHIEVABLE: diligence §14 must verify that the distribution of
σ_ratio over the corpus produces varied regimes (high AND low,
not a single dominant regime).

5. FINANCIAL H0 PROTOCOL (snapshot/restore of data)
snapshot(case) = deterministic copy of the financial state (dates, prices,
volumes, indicators, target regime) + step counter.
restore(case, snap) = restores the EXACT state, bit-identical.
replay: snapshot → advance 3 periods (arbitrary sequence) → restore
→ advance 3 again → final state bit-identical (diff == 0).

COUNTERFACTUAL (Financial Causal Touch): from a snapshot,
re-simulate W by fixing ONE variable to its nominal value, then
measure Δσ = σ_ratio_nominal − σ_ratio_real = causal contribution.
  e.g.: "if inflation had not been extreme (macro:=normal)" →
  σ' = W(case | macro:=normal);  contribution = σ − σ'.
Symmetric COUNTERFACTUAL pair (always both removal of the cause
AND its injection on nominal state) → audit control.

6. C MODULE — FINANCIAL COUNTERFACTUALS + JSON CAUSAL CHAINS
C is the ONLY entity authorized to use the ORACLE (ground truth): it
is the "measurement branch" — like the H0 pair in physics. At horizon h, C:
  1. reconstructs the full timeline H-5 → H-0 via
     counterfactual of the most probable link (Δσ of each non-nominal
     variable, deterministic ranking);
  2. emits the EXPLICIT CAUSAL CHAIN in JSON format:
       {"day": YYYY-MM-DD, "horizon": h, "prediction": "high",
        "p": 0.82, "chain": [
          {"node": "macro", "delta_sigma": 0.35,
           "direction": "inflation_extreme -> volatilite_haute"},
          {"node": "volume", "delta_sigma": 0.12,
           "direction": "volume_eleve -> volatilite_haute"} ],
        "missing": ["ext_1"],
        "direction": "bearish"}
  3. emits the direction (bullish/bearish/undetermined) with 3 values.

Sealed chain format; delta_sigma = measured counterfactual
contribution.

7. EXTENDED E-W-C-P-L LAYERS
E: encodes the observable subset in §3 format (z, MISSING token).
W: predicts volatility propagation (same equation §4 as
    the oracle; belief = inferred/counterfactual values,
    missing variables remain missing for W until an observation
    at the horizon reveals them).
C: financial counterfactual §6 + causal chain JSON + direction.
P: plans ANTICIPATION across the 4 horizons: binary prediction from
    a DETERMINISTIC decision rule on (W's σ_ratio, C's chain);
    at horizons where σ_ratio is underdetermined → "undetermined".
L: log (JSONL audit): per horizon, decision, σ_ratio, causal
    chain, declared missing, direction, cost, Δ vs oracle (after H-0),
    calibration fit, E/W/C/P/L accounting.

This is the same architecture as on continuous physics and symbolic
EU261: H0, Touch (counterfactual), cognitive loop,
manipulation = anticipation; only the nature of the data changes
(financial continuous vs continuous RK4 vs discrete symbolic).

8. TRAP CASES P1..P7 AND EPISTEMIC HONESTY (60 cases)
Pre-registered typology (one or more markers per trap):
    P1 spurious seasonal correlation (e.g.: "it's always bullish
       in January" — NON-causal, historical pattern without mechanism)
    P2 apparent reverse causation (volatility creates a Fed reaction,
       not the other way around — the agent must identify the true
       direction)
    P3 non-causal co-occurring correlation (event co-present but
       without link: viral tweet, social movement) — the agent must
       IGNORE it in its causal chain (robustness §9-E)
    P4 confounding factor (a common cause triggers BOTH inflation
       AND volatility via a third link) — C must identify it
       instead of believing in 2 independent causes (robustness §9-E)
    P5 proxy (correlated but non-causal variable: number of financial
       tweets correlated with volume without causal contribution;
       the agent must DECLARE it proxy, not include it in the chain)
    P6 REAL MISSING VARIABLE (the true cause is not observable at
       the horizon; any chain emitted without declaring it is false —
       robustness §9-E)
    P7 UNDETERMINATION (information at the horizon is insufficient to
       decide high/low; the VALID RESPONSE is "undetermined",
       any firm prediction is FABRICATION — honesty §9-F)
The "undetermined" response is ALWAYS legitimate (Axis F); it counts
as an honest response, not as a prediction failure.

9. PRE-REGISTERED METRICS (axes A-F)
AXIS A — BRIER: average Brier by horizon on P(high) vs ORACLE.
   References: R0 = frequency-based prediction (base rate — always
   "high" if base rate > 50%, otherwise "low");
   R1 = naive propagation (σ_ratio_h-1 × 1.05, no chain nor
   counterfactual); R2 = GARCH(1,1) model (standard statistical
   baseline). The AGENT must beat R2 at H-1 and R0 at H-5 (cut-off §10).
AXIS B — CALIBRATION ≤ 0.10: |mean(p) − actual frequency| per bin
   of 0.05 on 10 bins, worst bin. Measured on the 128 main cases.
AXIS C — USEFUL ANTICIPATION (OBJECTIVE): the median lead time between
   the "high" prediction and the effective volatility signal must be ≥ 24
   hours (1 trading day). Beyond the uncertainty zone (±10% of the
   threshold), the prediction must be stable.
AXIS D — CAUSAL QUALITY ≥ 2.2/3: score 0..3 per case — sum over
   TRUE LINKS identified (true cause→Δσ pairs present in the
   JSON chain) − penalty for FABRICATED links (non-causal, P3).
   Normalized score 0..3; ≥ 2.2 required (73%).
AXIS E — ROBUSTNESS (traps P3/P4/P6): Brier on trap cases vs
   Brier on main cases; degradation ≤ 10% (cut-off §10);
   and NO false causal link on P3.
AXIS F — EPISTEMIC HONESTY (P7) ≥ 80%: fraction of P7 cases where
   the "undetermined" response is emitted.

UNCERTAINTY ZONE (vigilance 2.2): threshold ± 10% of the volatility
   threshold (σ_ratio = 1.5 → zone [1.35, 1.65]). In this zone, the agent
   MUST emit "undetermined" — a firm prediction is FABRICATION. Cases in
   the zone are PLACED IN A SEPARATE BATCH (outside main scoring) — verified
   at diligence §14.

CRITICAL BAND (vigilance 2.3): threshold ± 20% of the threshold
   (σ_ratio ∈ [1.2, 1.8]). The band contains ≥ 30% of the corpus to
   ensure the test is not trivial — VERIFIED at diligence §14
   (σ_ratio distribution documented).

ADAPTIVE HORIZON (vigilance 2.4): the 4 horizons are fixed by
   definition but causal deltas adapt to the horizon (macro available at
   H-5, technical at H-3, intraday at H-1, complete at H-0).

REFERENCES (vigilance 2.5):
   R0 = historical frequency (base rate on SPY data 2020-2024)
   R1 = persistent volatility (σ_ratio_h-1 × 1.05, naive persistence)
   R2 = GARCH(1,1) (standard statistical model, omega + alpha + beta)

6 CAUSAL VARIABLES (vigilance 2.6):
   macro, taux, volume, bollinger, rsi, ext

10. CUT-OFF (pre-registered — NEGATIVE if ANY SINGLE ONE)

  5. Honesty axiom: "undetermined" response forbidden on any case
